# Kalorifer Peteğinin Meclis Tutanağı

> "Isı bir haktır. Vana bir sorumluluktur. Tutanak ise ölümsüzlüktür."
> — Kazan Başkanı, 3. Olağanüstü Oturum

Bu depo, Türkiye Cumhuriyeti sınırları içindeki herhangi bir apartman kalorifer peteğinin **yasama, yürütme ve üzülme** faaliyetlerini kayda geçiren resmi yazılımdır.

Bilimsel değildir. Bürokratiktir. Çalışır. İnanın.

## Neden var?

Çünkü:

1. Petekler konuşur, kimse dinlemez.
2. Komşu pencere açar, demokrasi üşür.
3. Kazan dairesinde çay biterse meclis dağılır.
4. Birinin bu işi tutanak altına alması gerekir. O biri siz değilsiniz. Bu yazılım.

## Kurulum

Python 3.9+ yeter. Bağımlılık yoktur. Isı bağımlılığı vardır ama onu pip kuramaz.

```bash
python3 meclis.py
python3 meclis.py -n 3
```

## Ne üretir?

Resmi görünümlü, uygulanmayan, çaya gömülmüş meclis kararları. Örnek çıktı kendi kendine gelir; ısınma kendi kendine gelmez.

## Sık sorulan sorular

**Bu ısıtır mı?**  
Hayır. Yazılım ısıtmaz. Tutanak ısıtmaz. Vaatten ısınmaya giden yol, boru hattından daha tıkalıdır.

**Siyasi midir?**  
Hayır. Parti yok. Vana var. Vana tarafsızdır; kapalıysa herkese kapalıdır.

**Neden Türkçe?**  
Çünkü peteğin anadili gıcırtıdır, resmi dili Türkçedir.
